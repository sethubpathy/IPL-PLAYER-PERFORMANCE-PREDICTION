Machine Learning Pipeline & Operational Integrity
1. Target Variable Formulation

In modern T20 cricket analytics, single-dimension metrics (e.g. batting average or bowling economy alone) fail to capture all-round player contributions. The model targets a composite performance metric:

Target = batting_runs + (20 × wickets)

This metric rewards both substantial run scorers and key wicket-takers on an equivalent, fantasy-calibrated scale.

2. Respecting Option C & Data Authenticity

As instructed, we do not replace or retrain the model. The web application strictly utilizes the verified outputs of the trained model from:

  • IPL_Random_Forest_Predictions.csv (4,085 test predictions across 2021–2023)
  • IPL_Player_Match_Performance.csv (21,716 historical match records)
  • IPL_Feature_Importance.csv (Exact 12 feature weights)
  • IPL_Model_Evaluation_Metrics.csv (Official R², MAE, RMSE metrics)
